How to use

使用說明

預覽、免費發布、以及之後怎麼自己修改。

一、網站檔案有哪些

  • index.html：網站骨架與這頁說明。
  • data.js：所有行程、餐廳、清單、照片設定都在這裡，平常只需要改這個。
  • style.css：顏色與版面。最上面 :root 可以換主色。
  • app.js：網站功能程式，不需要修改。

二、在自己電腦預覽

  1. 把收到的壓縮檔解壓縮成一個資料夾。
  2. 直接雙擊 index.html，用 Chrome、Safari 或 Edge 開啟即可。
  3. 照片、天氣、地圖需要連網才會顯示。

三、免費發布成網址（Netlify Drop，最簡單）

  1. 電腦開啟 app.netlify.com/drop。
  2. 把整個網站資料夾（裡面有 index.html 的那個）拖進網頁中間的框框。
  3. 幾秒後會得到一個 xxxx.netlify.app 的網址。
  4. 一小時內點畫面上的「Claim」或「Sign up」免費註冊並認領網站，否則網站會被自動刪除。
  5. 認領後可在 Site configuration → Change site name 改成好記的名字，例如 our-hokkaido-2026。
  6. 把網址傳給男朋友，手機用 Safari／Chrome 開啟，可「加入主畫面」當成 App 使用。

之後要更新網站

在電腦改好檔案後，到 Netlify 該網站的「Deploys」頁面，把整個資料夾再拖進去一次，網址不變、內容就更新了。

備選：GitHub Pages

  1. 註冊 GitHub，按右上角「+」→ New repository，名稱隨意，選 Public。
  2. 在新倉庫頁面按「uploading an existing file」，把四個檔案拖進去，按 Commit changes。
  3. 到 Settings → Pages，Source 選 Deploy from a branch、Branch 選 main，按 Save。
  4. 約一分鐘後會出現 帳號.github.io/倉庫名 的網址。之後可以直接在 GitHub 網頁上點 data.js → 鉛筆圖示線上修改。

四、修改行程（data.js 的 DAYS）

建議用免費的 VS Code 開啟 data.js（記事本也可以）。每一天長這樣，每個行程點是一行 { ... }：

{ time: '15:40-17:30', kind: 'food', title: '金森紅磚倉庫・幸運小丑',
  desc: '逛店拍港景，點中華雞腿漢堡。',
  stay: '約 1 小時',              ← 預計停留（可省略）
  move: '飯店步行 10-15 分',       ← 交通時間（可省略）
  addr: '函館市末廣町…',          ← 地址（可省略）
  q: 'Lucky Pierrot Bay Area Main Store',  ← Google Maps 搜尋用名稱
  img: 'bayArea',                 ← 照片代號（對應 PHOTOS）
  tag: '已訂' },                  ← 標籤：已訂／待確認／備案／彈性
  • 新增景點：複製一整行 { ... }, 貼在想要的位置再改內容。
  • 刪除景點：把那一整行刪掉。
  • 注意每個 { } 後面要有逗號，文字要放在單引號 ' ' 裡；文字裡如果要用單引號，請改用「」。
  • 改壞了網站變空白？用 Ctrl+Z 回到上一步存檔，或用原本的備份檔覆蓋。

五、修改照片

  • 景點照片設定在 data.js 最上面的 PHOTOS。
  • 想用自己的照片：在網站資料夾裡建一個 photos 資料夾放入圖片，然後寫 myToya: { src: 'photos/toya.jpg', credit: '自己拍的' },，再到行程點寫 img: 'myToya'。
  • Wikimedia 照片需標示作者與授權，網站已在照片右下角自動顯示，請不要刪掉。

六、修改餐廳（data.js 的 FOODS）

每間餐廳一筆，營業時間 hours、公休 closed、價格 price、推薦 dish。查不到請寫 待確認，網站會用紅字提醒。若想放餐廳照片，可加 photo: 'photos/xxx.jpg'。行程點寫 food: '餐廳代號' 就會在行程裡顯示餐廳小卡。

七、預算、清單、照片牆的資料存在哪裡

  • 預算、清單存在這支手機或這台電腦的瀏覽器，重新整理不會消失；但換裝置、換瀏覽器或清除瀏覽資料就看不到。
  • 兩人要共用同一份預算：一人在預算頁按「匯出備份」，把檔案用 LINE 傳給對方，對方按「匯入備份」即可同步。
  • 照片牆的照片只存在上傳的那台裝置，不會上傳到網路，也不會被別人看到。想跟男友共享照片，建議另外開一本 Google 相簿共享相簿。
  • 預算頁的匯率請到 台灣銀行牌告匯率 查最新的日圓「現金賣出」再填入。

八、資料來源

  • 行程、時間、價格：依你提供的 PDF 行程簡報。
  • 餐廳營業時間與公休：以 Google Maps 為準（2026/11/17 查詢），出發前建議再看一次。
  • 天氣：Open-Meteo（CC BY 4.0），警報請看日本氣象廳。
  • 照片：Wikimedia Commons 與維基百科條目照片，作者與授權標在每張照片上。
