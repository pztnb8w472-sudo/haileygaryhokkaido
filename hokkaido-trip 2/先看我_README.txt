北海道旅行網站 HOKKAIDO TRAVEL 2026.12.14 — 12.21
================================================

【預覽】雙擊 index.html，用 Chrome / Safari / Edge 開啟（需連網才會顯示照片、天氣、地圖）。

【免費發布】
1. 電腦開 https://app.netlify.com/drop
2. 把「整個資料夾」拖進去，得到 xxxx.netlify.app 網址
3. 一小時內按 Claim / Sign up 免費註冊認領，否則網站會被刪除
4. 之後要更新：到該網站的 Deploys 頁，再把資料夾拖進去一次

【修改內容】只要改 data.js（行程 DAYS、餐廳 FOODS、清單 CHECKLIST、照片 PHOTOS）。
詳細教學：打開網站 → 「使用說明」頁。
